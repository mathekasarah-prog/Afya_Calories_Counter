# 🌿 Afya Calorie Counter

> Track your meals. Understand your calories. Live healthier.

Afya Calorie Counter is a simple and user-friendly web application that helps users track the foods they consume throughout the day and monitor their total calorie intake.

The application allows users to add food items, record their calorie values, view their daily food list, remove individual items, calculate their total calorie consumption, and reset their daily records.

Food calorie information can also be retrieved from a local JSON database using the JavaScript Fetch API.

## 📌 Project Overview

Afya Calorie Counter was developed as a JavaScript project to demonstrate practical use of JavaScript, DOM manipulation, event handling, localStorage, and the Fetch API.

The application provides a simple interface where users can:

- Add food items and their calorie values
- Look up calorie information from a local food database
- Display all foods added during the day
- Remove individual food items
- Calculate total calories consumed
- Reset the daily calorie counter
- Store food data in the browser using localStorage

The project combines a clean, responsive interface with JavaScript functionality to create a practical calorie-tracking tool.
